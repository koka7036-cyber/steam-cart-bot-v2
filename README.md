# Steam Card Bot v2

Приватный Telegram-бот для обработки заказов на наборы карточек Steam.

## Переносимая версия Windows 11

- Запуск выполняется через `start.bat` рядом с файлами бота; путь `C:\CardBot` больше не требуется.
- `run_bot.ps1` использует папку, в которой находится сам скрипт, даже если запускать его из другого места.
- По умолчанию файлы данных (`vouchers.json`, `inventory_cache.json`, `steam_session.json`, настройки и журналы) хранятся рядом с `bot.py`. При переносе переносите **всю папку бота целиком**, включая эти файлы. Можно задать отдельную папку данных переменной среды `CARD_BOT_DATA_DIR`.
- Путь к ASF можно задать переменной среды Windows `CARD_BOT_ASF_DIR`. Если она не задана, запускающий файл ищет ASF в подпапке `ASF-win-x64 (1)` рядом с ботом.
- Скрипт `update_bot.ps1` намеренно заблокирован: прежняя версия была привязана к фиксированным папкам и ветке `main`. Переносимый механизм обновления ещё не реализован. Запускатель также остановится с понятной ошибкой, если не найдены обязательные настройки Windows или Python Launcher.

## Автозапуск Windows 11 через Telegram

В административном меню **«⚙️ Настройки»** есть переключатель **«Автозапуск Windows: ВКЛ/ВЫКЛ»**. Он управляет задачей Планировщика заданий `CardBot - AutoStart`. Задача запускает `start.bat` из текущей папки проекта после входа пользователя в Windows.

Автозапуск не означает работу при выключенном компьютере. Для обработки заказов ПК и интернет должны оставаться включёнными, а Windows не должна переводить компьютер в сон.

## Безопасность и проверка

Не отправляйте токены, пароли, Steam cookies/session, ASF maFile или FunPay golden key в чат или GitHub. Runtime-файлы, сессии и секреты не должны попадать в репозиторий.

До реальных продаж необходимо проверить синтаксис, тесты, первый запуск, подтверждение оплаты, резервирование товара и отсутствие повторной выдачи. Текущая ветка не считается готовым релизом, пока эти проверки не пройдены.
