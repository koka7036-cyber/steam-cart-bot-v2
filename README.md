# Steam Card Bot v2

Приватный Telegram-бот для обработки заказов на наборы карточек Steam.

## Автозапуск Windows 11 через Telegram

В административном меню **«⚙️ Настройки»** есть переключатель **«Автозапуск Windows: ВКЛ/ВЫКЛ»**. Он управляет единственной задачей Планировщика заданий `CardBot - AutoStart`, а не значением реестра. Состояние читается из Планировщика; команда переключения разрешена только владельцу бота.

При включении задача запускает `C:\CardBot\start.bat` после входа текущего пользователя Windows. Скрипт запуска сначала проверяет обновления, запускает ASF при необходимости и удерживает перезапуск бота. При выключении задача отключается, но уже запущенный бот продолжает работать до штатной остановки; переключатель отвечает только за автоматический запуск при следующем входе в Windows. Это предотвращает остановку текущего Telegram-сеанса командой, которую он сам обрабатывает.

Для работы переключателя на компьютере должны присутствовать `C:\CardBot\start.bat`, `C:\CardBot\toggle_autostart_task.ps1` и файлы бота в `C:\CardBot`. Обновление через `update_bot.ps1` переносит оба вспомогательных скрипта из `main`; изменения должны попасть в `main`, прежде чем штатный updater сможет их забрать.

**Важно:** задача запускается после входа пользователя в Windows, а не на экране входа до авторизации. Компьютер должен оставаться включённым и не уходить в сон, если нужна непрерывная работа.

## Обновление и тестирование

`update_bot.ps1` получает код только из `main` и перед изменениями создаёт резервные копии. Runtime-файлы (`vouchers.json`, `inventory_cache.json`, `steam_session.json`, `funpay_config.json`, журнал заказов, логи и резервные копии) не должны попадать в GitHub. Сначала проверь обычный запуск и безопасный тестовый заказ; не запускай второй экземпляр вручную.
