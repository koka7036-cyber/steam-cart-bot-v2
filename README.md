# Steam Card Bot v2

Приватный Telegram-бот для обработки заказов на наборы карточек Steam.

## Windows 11: установка автозапуска

Бот запускается из `C:\CardBot\start.bat`. Скрипт `install_autostart.ps1` регистрирует задачу Планировщика заданий для текущего пользователя Windows:

- запуск при входе пользователя в Windows;
- повторный запуск задачи при завершении процесса;
- защита от второго экземпляра остаётся в `run_bot.ps1`;
- установка задачи не запускает бота немедленно.

После обновления файлов из `main`, открой PowerShell от имени того же пользователя, который обычно запускает бота, и выполни:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File C:\CardBot\install_autostart.ps1
```

Затем проверь задачу `Steam Card Bot - AutoStart` в Планировщике заданий Windows. Чтобы проверить запуск сразу, вручную запусти `C:\CardBot\start.bat`.

**Важно:** задача срабатывает после входа пользователя в Windows, а не на экране входа до авторизации. Если компьютер перезагрузился и остался на экране входа, бот не стартует, пока пользователь не войдёт. Компьютер также должен оставаться включённым и не уходить в сон, если нужна непрерывная работа.

## Обновление и проверка

`update_bot.ps1` получает код только из `main`. Изменения из открытого PR не попадут на компьютер, пока PR не будет проверен и слит в `main`. Перед первым тестовым заказом проверь запуск и логи; сначала используй безопасный тестовый заказ, не запускай параллельно второй экземпляр.

## Защита данных

Не загружай в GitHub `vouchers.json`, `inventory_cache.json`, `steam_session.json`, `funpay_config.json`, логи, резервные копии или секреты из переменных окружения. Не включай автоматическую выдачу FunPay без отдельной проверки разрешённого сценария.
